# Board Extraction to jrit-board Implementation Plan

> For executors: tasks use checkbox syntax; execute in dependency order; a task is done when its
> acceptance check passes. No specific tooling, harness, or skills are assumed.

**Goal:** Move the Obsidian board out of loop-stack-session into a private, self-hosting `jroethel/jrit-board` repo carrying its own history, tracker, and config, leaving the recording convention behind.

**Approach:** Extract five board code paths plus every board design doc into a fresh repo with `git filter-repo`, make that repo a managed loop-stack repo with its own installer and a runnable vendored-script drift check, prove the render twice (once isolated, once into the real vault) before deleting anything, then delete the board's code, assets, tests, and config keys from loop-stack-session at HEAD and reconcile the one vendored file that deletion touches.
The removal is a forward deletion, never a revert of any `(#52)` commit.
Board design docs and session records stay in loop-stack-session as the historical record; only code, assets, tests, and the `LOOP_BOARD_*` config keys are deleted there.

**Tech stack:** POSIX-ish bash (macOS stock bash 3.2 compatible), `git`, `git-filter-repo`, `gh` CLI, Obsidian (Bases plugin).

**Source brief:** `docs/briefs/2026-09-11.I52.board-extraction-to-jrit-board-brief.md`

**Review:** Rubix review run 2026-09-11, two lenses (impacted maintainer, cold craft read); fifteen findings, all folded in. The changes they forced are marked `[rubix]` at their site.

### Task 1: Card TSV contract assertion

Depends on: none

The board lanes session cards by an exact status vocabulary and prefixes card titles with an exact marker vocabulary.
`scripts/board-cards.sh:61` falls unknown statuses through to `next-up` silently.
After the split that fall-through is in a different repo, so a status added or renamed here would mis-lane cards there with nothing failing.
This assertion closes that hole, and it lands before the extraction so the split never ships with it open.

**Files (exclusive ownership):**
- Modify: `tests/sessions/take-stock.sh` (append a new block before the final `echo "PASS: ..."` at line 80)

**Interfaces:**
- Consumes: `scripts/session-card.sh` (the terminal-status case arm at line 121, marked with the trailing comment `# closed vocabulary, a case statement not a regex`), `scripts/take-stock.sh` (the two marker assignments at lines 95 and 143)
- Produces: nothing other tasks consume. Task 7's removal must not touch this file.

**Acceptance check:** `bash tests/sessions/take-stock.sh` exits 0 `[executed-check]`

- [ ] Step 1: Append this block to `tests/sessions/take-stock.sh`, immediately before the existing final `echo "PASS: ..."` line:

```bash
# --- the card TSV contract: jrit-board's board-cards.sh lanes on these exact vocabularies, and its
# unknown-status arm falls through to next-up silently, so a status added or renamed here must fail
# HERE rather than mis-lane a card in a repo this suite cannot see ---
SC="$REPO/scripts/session-card.sh"
arm="$(grep -E '^[[:space:]]*[a-z|-]+\)[[:space:]]*;;[[:space:]]*# closed vocabulary' "$SC" \
        | sed -E 's/^[[:space:]]*([a-z|-]+)\).*/\1/')"
[ "$arm" = "done|blocked|handed-off|parked|aborted" ] \
  || fail "session-card.sh's terminal vocabulary is now '$arm'; jrit-board lanes on done|blocked|handed-off|parked|aborted and will silently mis-lane the difference"

mk="$(grep -oE '(marker|stale)=[a-z-]+' "$TS" | sed -E 's/^[a-z]+=//' | sort -u | paste -sd'|' -)"
[ "$mk" = "died-mid-work|went-stale" ] \
  || fail "take-stock.sh's marker vocabulary is now '$mk'; jrit-board reads exactly went-stale and died-mid-work"

# and no emitted row may ever carry a marker outside that pair
bad="$(bash "$TS" "$R" --cards | awk -F'\t' '$7 != "" && $7 != "went-stale" && $7 != "died-mid-work" {print $7}')"
[ -z "$bad" ] || fail "a --cards row carried the marker '$bad', outside the two-value vocabulary"
```

Verified during planning that `--full-history --no-merges` returns exactly the same 4/5/10/7/10 baseline while being rewrite-stable (plain `--full-history` returns 6/8/13/9/13 and would not match).
Every path in the filter-repo argument list is asserted to exist, not just the code paths, so a typo in a doc path cannot pass silently.

```bash
#!/usr/bin/env bash
# history.sh - the extraction proof, kept as a committed regression guard rather than a one-shot.
# The five board code paths must carry the same per-path commit counts they carried in
# loop-stack-session before the extraction, every path named in the filter-repo argument list must
# exist at HEAD, and the repo must be a single-branch tree with no inherited remote. Counting uses
# --full-history --no-merges because plain `git log -- <path>` applies history simplification, whose
# result can shift when filter-repo rewrites parentage even on a correct extraction.
set -uo pipefail
HERE="$(cd "$(dirname "$0")" && pwd)"
REPO="$(cd "$HERE/../.." && pwd)"
cd "$REPO" || exit 1
bad=0
note() { echo "BAD  $1"; bad=$((bad + 1)); }

count() {   # $1 path, $2 expected
  local got; got="$(git log --full-history --no-merges --oneline -- "$1" | wc -l | tr -d ' ')"
  [ "$got" = "$2" ] || note "$1 has $got commits, expected $2"
}
count scripts/board.sh 4
count scripts/board-cards.sh 5
count scripts/board-render-obsidian.sh 10
count assets/board 7
count tests/board 10

# every path the extraction was told to keep, asserted at HEAD
for f in scripts/board.sh scripts/board-cards.sh scripts/board-render-obsidian.sh \
         assets/board/Board.md assets/board/by-lane.base assets/board/by-repo.base \
         assets/board/loop-board.css \

         tests/board/spike-artifacts.sh tests/run.sh \
         docs/spikes/2026-09-02.I52.board-bases-spike-findings.md \
         docs/briefs/2026-08-30.I52.resume-board-brief.md \
         docs/briefs/2026-08-30.I52.resume-board-brief-rubix.md \
         docs/briefs/2026-08-31.I52.board-view-tech-brief.md \
         docs/briefs/2026-09-02.I52.obsidian-board-mvp-brief.md \
         docs/briefs/2026-09-11.I52.board-extraction-to-jrit-board-brief.md \
         docs/plans/2026-09-02.I52.obsidian-board-mvp-plan.md \
         docs/plans/2026-09-02.I52.obsidian-board-mvp-plan_loop.md \
         docs/plans/2026-09-11.I52.board-extraction-to-jrit-board-plan.md \
         docs/reviews/2026-09-02.I52.obsidian-board-mvp-batch-review.md \
         docs/reviews/2026-09-03.I52.board-mvp-integration-runbook.md \
         docs/archive/2026-09-07.I52.board-mvp-to-seam1-handoff.md; do

done
[ -d docs/plans/i52-manifests ] || note "missing at HEAD: docs/plans/i52-manifests/"
```

```bash
#!/usr/bin/env bash
# drift.sh - the nine files jrit-board copied verbatim from loop-stack-session are forks now: the
# eight scripts loop-setup vendors into every managed repo, plus tests/run.sh. This is how the
# accepted sync obligation stays detectable instead of remembered. SKIP (exit 0) when
# loop-stack-session is not on this host: a check that fails for an environmental reason gets
# ignored, and an ignored check is not a check. A real difference is a FAIL, and the message
# carries the exact one-line refresh per file - the same copy loop-setup's own refresh performs.
set -uo pipefail
HERE="$(cd "$(dirname "$0")" && pwd)"
REPO="$(cd "$HERE/../.." && pwd)"

VENDORED="scripts/gen-mirrors.sh scripts/tracker.sh scripts/graduate-parking.sh
scripts/migrate-tracker.sh scripts/lifecycle-lint.sh scripts/session-card.sh
scripts/handoff-log.sh scripts/take-stock.sh tests/run.sh"

SRC="${JRIT_BOARD_LOOP_STACK_ROOT:-}"
if [ -z "$SRC" ] && [ -f "$REPO/config/host.env" ]; then
  SRC="$( . "$REPO/config/host.env" >/dev/null 2>&1; printf '%s' "${JRIT_BOARD_LOOP_STACK_ROOT:-}" )"
fi
if [ -z "$SRC" ] || [ ! -d "$SRC" ]; then
  echo "SKIP: loop-stack-session not found (JRIT_BOARD_LOOP_STACK_ROOT unset, empty, or not a directory)"
  exit 0
fi

drift=0; fixes=""
for f in $VENDORED; do
  if [ ! -f "$SRC/$f" ]; then
    echo "GONE:    $f no longer exists in $SRC"; drift=$((drift + 1)); continue
  fi
  if [ ! -f "$REPO/$f" ]; then
    echo "MISSING: $f is not vendored here"; drift=$((drift + 1)); continue
  fi
  cmp -s "$REPO/$f" "$SRC/$f" || {
    echo "DRIFT:   $f"
    fixes="$fixes  cp \"\$SRC/$f\" \"$f\" && chmod +x \"$f\"
"
    drift=$((drift + 1))
  }
done

if [ "$drift" -gt 0 ]; then
  echo "FAIL: $drift vendored file(s) differ from $SRC"
  if [ -n "$fixes" ]; then
    echo "to refresh (this is exactly what loop-setup's own refresh does):"
    echo "  SRC=$SRC"
    printf '%s' "$fixes"
  fi
  exit 1
fi
echo "PASS: all nine vendored files match $SRC"
```
