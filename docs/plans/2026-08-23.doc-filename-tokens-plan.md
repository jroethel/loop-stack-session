# Doc filename tokens Implementation Plan

> For executors: tasks use checkbox syntax; execute in dependency order; a task is done when its
> acceptance check passes. No specific tooling, harness, or skills are assumed.

**Goal:** Enable bidirectional mapping between tracker items and their docs via filename tokens, with stable roadmap IDs and lint enforcement.

**Approach:** Extend the existing filename grammar from `YYYY-MM-DD-<slug>.md` to a unified dot-grammar that accommodates both tokened and untokened names, update all generators to emit tokens when known, extend the lint with grammar and R-tag checks, and add a grandfathering key so existing docs remain exempt.

**Tech stack:** Bash scripts (lifecycle-lint.sh, tracker.sh), shell renderers (setup.sh), markdown skills/docs.

**Source brief:** docs/briefs/2026-08-22-doc-filename-tokens-brief.md

## Global constraints

Filename conformance regex: `^[0-9]{4}-[0-9]{2}-[0-9]{2}(\.[BIR][0-9]+)*\.[a-z0-9-]+\.md$`
Token letter semantics: I = Issues-lane GitHub issue, B = Backlog-lane (idea label) GitHub issue, R = Roadmap item (stable assigned ID)
Grandfathering key name: `filename-grammar-since:`
Template generation this plan lands: `template-version: 6` (5 is taken by the separately-committed lifecycle-lint done-gate doctrine; straight bump from 4 is fine if 5 has not landed)
Roadmap R-tag format: `[R<n>]` where n is monotonically assigned, never reused, and survives reorders
House style: no em dash character anywhere (plain "-" only), one full sentence per line in prose, aligned pipe tables under 110 chars

- [ ] Step 1: Replace `stem_of()` in `scripts/lifecycle-lint.sh:36-51` with this exact implementation (it parses both grammars and strips leading token segments; the type-suffix stripping keeps its current three cases and never strips `-batch-review`, which reviews never feed into stem_of):

```bash
# stem_of <basename>: prints the topic stem of a dated doc filename, dash or dot grammar;
# dot names have their leading [BIR]<n> token segments stripped before the stem. Returns 1 for
# undated or foreign filenames, which never participate in lifecycle checks.
stem_of() {
  local s="$1"; s="${s%.md}"
  case "$s" in
    [0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9].*)
      s="${s:11}"                                # dot grammar: strip date + '.'
      while :; do                                # drop leading [BIR]<n> token segments
        case "$s" in
          [BIR][0-9]*.*) s="${s#*.}" ;;
          *) break ;;
        esac
      done
      ;;
    [0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]-*)  # legacy dash grammar, unchanged
      s="${s:11}"
      ;;
    *) return 1 ;;
  esac
  case "$s" in
    *-plan_loop) s="${s%-plan_loop}" ;;
    *-plan)      s="${s%-plan}" ;;
    *-brief)     s="${s%-brief}" ;;
  esac
  printf '%s\n' "$s"
}
```

- [ ] Step 2: Add class f (filename grammar) to `scripts/lifecycle-lint.sh`, inserted after the class e block and before the final `exit "$found"`. Exact implementation:

# (f) filename grammar - runs only when the adopting key is present (same absence-skips pattern
# as the tracker mode): docs in the four lanes dated on/after the key's date must match
# <date>.<tokens>.<slug>.md; older docs are exempt; lanes outside the four are never scanned,
# and the non-recursive *.md glob keeps subdirs like docs/reviews/unit-logs/ out of the scan.
# Reads the key with the existing fm() helper near the top of this script; no new helper.
SINCE=""
[ -f config/repo-state.md ] && SINCE="$(fm config/repo-state.md filename-grammar-since)"
if [ -n "$SINCE" ]; then
  for lane in docs/briefs docs/plans docs/handoffs docs/reviews; do
    for f in "$lane"/*.md; do
      [ -e "$f" ] || continue
      b="$(basename "$f")"
      d="$(date_of "$b")"
      case "$d" in
        [0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]) ;;
        *) continue ;;                          # undated names never participate
      esac
      [[ "$d" < "$SINCE" ]] && continue         # grandfathered (ISO dates compare lexically)
      printf '%s\n' "$b" | grep -Eq '^[0-9]{4}-[0-9]{2}-[0-9]{2}(\.[BIR][0-9]+)*\.[a-z0-9-]+\.md$' \
        || lint f "$f" "filename does not match <date>.<tokens>.<slug>.md (grammar since $SINCE)"
    done
  done
fi
```

- [ ] Step 3: Add class g (roadmap R-tags) directly after class f. It runs unconditionally (pure filesystem); duplicates and malformed bracket groups are flagged, absence is never flagged. # (g) roadmap R-tags - unique well-formed tags, malformed [R...] groups flagged, absence never.
if [ -f ROADMAP.md ] && [ -n "$(grep -oE '\[R[^]]*\]' ROADMAP.md 2>/dev/null)" ]; then
  gfindings="$(grep -oE '\[R[^]]*\]' ROADMAP.md | awk '
    { if ($0 ~ /^\[R[0-9]+\]$/) seen[$0]++
      else print "malformed\t" $0 }
    END { for (t in seen) if (seen[t] > 1) print "duplicate\t" t }
  ')"
  while IFS=$'\t' read -r kind t; do
    [ -n "$t" ] || continue
    lint g ROADMAP.md "$kind R-tag '$t'"
  done <<< "$gfindings"
fi
```
