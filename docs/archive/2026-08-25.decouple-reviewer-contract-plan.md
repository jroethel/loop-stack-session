# Decouple the Reviewer-Conduct Contract Implementation Plan

> For executors: tasks use checkbox syntax; execute in dependency order; a task is done when its
> acceptance check passes. No specific tooling, harness, or skills are assumed.

**Goal:** Make loop-stack own its reviewer-conduct contract in-repo, removing the cross-repo dependency on rubix-review and deleting the hash-guard/wiring machinery that rubix-review backlog #7 and #8 were meant to harden.

**Approach:**
The contract text is generic reviewer conduct, not specific to rubix-review's lenses, and loop-review and loop-drive each dispatch their own reviewer subagents rather than routing through rubix-review.
So loop-stack commits its own canonical copy at `config/reviewer-conduct-contract.md` and symlinks it into both consuming skills at install time, mirroring the existing `config/routing/model-benchmarks.md` pattern (install.sh section 2b).
The wiring is symlink-only by design: the source is co-located in this checkout, so no cross-mount copy is needed, copy-mode (and its staleness surface) is intentionally gone, and a symlink failure leaves the leaf absent so reviewers fail closed rather than run uncontracted.
The cross-repo self-install, clause-grep guard, and host-path drift check are removed; rubix-review keeps its own independent contract and needs no code change.

**Tech stack:** POSIX/bash shell (install.sh, gate scripts), Markdown.
**Source brief:** none; this plan supersedes the design chosen in loop-stack `docs/briefs/2026-08-23.rubix-standalone-skill-brief.md` (single-source across repos), by explicit user decision to decouple.

## Global constraints

- The canonical contract lives only at `config/reviewer-conduct-contract.md` in this repo; no verbatim contract body appears in any tracked `skills/*/SKILL.md`.
- The wiring mirrors section 2b (`model-benchmarks.md`): `ln -sfn "$REPO/config/..." "$SKILLS_DIR/<consumer>/references/..."`, target `$SKILLS_DIR` (not the STYLE-branched agents/claude split the old 2c used), with a skip-note when the consumer skill dir is absent.
- Symlink-only: no copy fallback. A failed `ln` warns and leaves the leaf absent (reviewers fail closed); it must never abort the installer under `set -e`.
- loop-review and loop-drive still fail closed when the contract file is absent (never review uncontracted); the recovery instruction is report-only and must never run an installer from the repository under review.
- No reference to rubix-review as the contract owner, to `LOOP_STACK_RUBIX_ROOT`, to `_clauses_ok`, or to cloning rubix-review for the contract remains in `install.sh`, `README.md`, `config/host.env.template`, or `tests/gates/reviewer-contract.sh`. The legitimate mentions of the *optional* Rubix review (README lines 21, 38, 75) stay.
- rubix-review gets no code change. Its backlog #7 and #8 close as superseded.

# 2c. reviewer-conduct contract: loop-stack owns the canonical copy in config/; symlink it into each
#     consuming skill's references/ so repo edits stay live (mirrors 2b's model-benchmarks wiring).

    cdir="$SKILLS_DIR/$consumer/references"
    mkdir -p "$cdir"

    fi
  else
    echo "note: $consumer skill not installed; skipping reviewer-conduct-contract.md symlink"
  fi
done
